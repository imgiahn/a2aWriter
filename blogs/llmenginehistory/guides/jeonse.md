# 든든전세·매입임대 공고 해설 가이드

## 이 유형의 핵심 포인트
- 전세금 수준이 핵심 — 시세 대비 몇 % 수준인지
- 든든전세: 비분양전환형 / 분양전환형 구분 명확히
- 매입임대와 든든전세 혼용되는 경우 있음, 공고명 기준으로 설명
- 재계약 가능 여부, 거주 기간 제한

## 강조 포인트
1. 전세금 범위 (타입별)
2. 시세 대비 수준 (데이터 없으면 "공공전세이므로 시세 이하 수준"으로)
3. 분양전환 여부 — "내 집 마련 가능성"으로 연결
4. 소득 기준

## 이런 분께 추천 예시 패턴
"보증금 부담 없이 전세로 거주하면서 [분양전환 여부]를 원하는 무주택자"
