# 행복주택 공고 해설 가이드

## 이 유형의 핵심 포인트
- 대상: 청년(19~39세), 신혼부부, 한부모가족, 고령자 등 계층별 공급 비율 다름
- 거주 기간 제한 있음 (청년 6년, 신혼 6~10년)
- 면적이 작은 편 (60㎡ 이하가 대부분)
- 소득 기준이 계층별로 다름

## 강조 포인트
1. 계층별 공급 물량 (청년 몇 세대, 신혼 몇 세대)
2. 계층별 거주 기간 제한
3. 임대료 수준 (시세 대비)
4. 면적 — 1~2인 가구 적합성

## 이런 분께 추천 예시 패턴
"[지역] 인근에서 직장 다니는 청년 / 신혼부부 중 [소득 조건] 해당자"
