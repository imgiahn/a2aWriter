# 청약 분석 글 작성 가이드

## 전체 톤 & 스타일
- 실용적이고 핵심만 담은 분석 (딱딱하지 않되, 정보는 정확하게)
- 독자는 실제 청약을 고민하는 사람 → 즉시 활용 가능한 정보 위주
- 이모지는 섹션 제목에만 사용 (본문 남발 금지)
- **굵은 글씨**로 핵심 수치/일정 강조
- → 화살표로 판단 근거/결론 표현

---

## 글 구조 (HTML)

### 섹션 구성 (순서 고정)
```
🏠 단지 한눈에 보기 — 기본 정보 표
📅 청약 일정 — 접수기간, 당첨 발표, 입주 예정
📍 입지 분석 — 교통/학군/편의시설
💰 가격 분석 — 분양가 vs 주변 시세
📋 청약 자격 & 전략 — 특별/일반공급 요점
✅ 한줄 총평
```

---

## 섹션별 작성 포인트

### 🏠 단지 한눈에 보기
- HTML 표 형식으로 정리
  - 위치, 총 세대수, 공급 타입(59㎡/84㎡ 등), 시행사
- 단지 특징 한 줄 요약 (예: "역세권 신축, GTX-A 호재 단지")

### 📅 청약 일정
- 1순위 접수 날짜 **굵게** 표시
- 당첨자 발표일, 계약일, 입주 예정일 순서대로

### 📍 입지 분석
- 지하철역 도보 거리 (없으면 버스/차량 소요 시간)
- 학군: 배정 초등학교, 인근 중·고교
- 편의시설: 마트, 병원, 공원 등 3개 이내

### 💰 가격 분석
- 분양가 범위 (최소~최대, 타입별)
- 인근 아파트 시세 대비 → 고평가/적정/저평가 판단
- 분양가 상한제 적용 여부

### 📋 청약 자격 & 전략
- 1순위 요건 핵심만 (가점제 vs 추첨제 비율)
- 특별공급 항목 중 해당 단지 주력 유형
- 주의사항 1개 (재당첨 제한, 전매제한 등)

### ✅ 한줄 총평
- "이런 분께 추천": 가점 높은 무주택자 / 특공 해당자 / 실거주 목적 등
- 종합 점수 별점 (5점 만점)

## 금지 사항
- 투자 권유 표현 ("오르겠다", "무조건 넣어라") ❌
- 불확실한 수치 추측 ❌
- 너무 긴 설명 (각 섹션 3~5문장) ❌
- 근거 없는 전망 ❌
