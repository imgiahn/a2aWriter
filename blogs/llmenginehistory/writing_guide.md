# 청약 공고 해설 공통 작성 규칙

## 독자 전제
청약에 관심 있는 사람. LH, 국민임대, 행복주택, 분양전환 등 기본 개념은 안다.

## 절대 금지
- "LH(한국토지주택공사)란..." 설명
- "국민임대주택이란..." 설명
- "청약통장이란..." 설명
- "공고문을 참고하세요"
- "알아보겠습니다", "살펴보겠습니다"
- 같은 말 반복

## 반드시 포함
- **이번 공고의 핵심 1~2줄** (제일 처음)
- **신청 마감일** (굵게 강조)
- **이런 분께 추천** (마지막 문단, 명확하게)

## HTML 구조 (순서 고정)
```
1. 공고 한눈에 보기 (표)
2. 이번 공고 핵심 포인트
3. 신청 일정
4. 신청 자격
5. 주거 조건 (임대료/전세금/분양가 등)
6. 이 지역 특성 (2~3문장)
7. 이런 분께 추천
```

## 이 지역 특성 작성법
공고 지역의 생활권·교통·수요를 2~3문장으로.
"이 지역은 좋습니다" 수준이 아니라 구체적 특성.
예: 김포 → 서울 접근성, GTX-D 노선 이슈 언급
예: 이천 → SK하이닉스 인근 직주근접 수요
예: 안양 → 수도권 남부 출퇴근 수요
