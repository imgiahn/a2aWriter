# LH 청약 공고 해설 작성 규칙

## 독자 전제
청약에 관심 있는 사람. LH, 국민임대, 행복주택, 분양전환 등 기본 개념은 안다.
이 글을 읽고 "나는 신청해야 해? 말아야 해?"를 판단할 수 있어야 한다.

---

## 절대 금지
- 공고명을 제목으로 그대로 사용
- "이번 공고는..." 으로 시작
- "LH(한국토지주택공사)란..." 설명
- "청약이란...", "국민임대란..." 설명
- "공고문을 확인하세요", "알아보겠습니다", "살펴보겠습니다"
- 데이터 없는 항목 억측
- 의미 없는 반복, 뻔한 마무리

---

## 제목 규칙 (중요)
공고명 통째로 복사 금지 (블록번호·괄호·"입주자모집공고" 제거).
단지명·브랜드명이 있으면 반드시 제목에 포함 — 독자가 그 이름으로 검색한다.

나쁜 예: "파주운정3 A12BL(해오름12) 10년 공공임대주택리츠 예비입주자모집(무순위) 해설"
         "분당 낙생지구 신혼희망타운 분양가·청약일정"  ← 단지명 누락
좋은 예: "파주 운정신도시 공공임대 예비입주자 모집, 분양전환 조건은?"
         "e편한세상 분당 퍼스트빌리지 신혼희망타운 청약 신청 조건"

패턴 예시:
- 단지명 있음: "[단지명] [유형] 청약 신청 조건"  /  "[단지명] [유형], [핵심 조건]은?"
- 단지명 없음: "[지역] [유형] 신청 조건 총정리"  /  "[지역] [유형], 누가 신청하면 좋을까?"

## HTML 글 구조 (순서 고정)

```
[1] 기본 정보 표 (가운데 정렬)
    항목: 단지명 / 위치 / 총 세대수 / 이번 공급 / 입주 예정일
          재당첨 제한 / 전매 제한 / 거주 의무
    데이터 없는 항목은 행 생략

[2] 사업 개요
    단지·지역 특성(교통·생활권·입지) + 주목해야 하는 이유

[3] 분양가 (임대 타입은 "임대 조건")
    타입별 분양가 표 + 평당 환산 + 계약금/중도금/잔금

[4] 청약 조건
    신청 자격 / 우선공급 / 소득·자산 기준

[5] 청약 일정
    날짜 리스트 (마감일 굵게)
```

## 평당 분양가 계산 방법
공급면적(㎡) × 0.3025 = 평수
분양가 ÷ 평수 = 평당 가격 (만원 단위로 표기)
예: 84㎡ → 25.4평, 5억 9,976만원 ÷ 25.4평 ≈ 2,361만원/평

---

## 데이터 없을 때
억측 금지. 해당 항목 자연스럽게 생략.
"공고문 확인 필요" 표현 금지.
